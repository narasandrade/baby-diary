# Baby Diary

An app to track your baby's routine.

## Tech Stack - Frontend

- Vite
- React
- TypeScript
- SCSS

## Tech Stack - Backend

- Node.js
- Express
- MongoDB

## Installation and Usage

### Clone the repository

```sh
git clone https://github.com/narasandrade/baby-diary.git
cd baby-diary
```

### Setup Frontend

### 1. Go to baby-diary-frontend folder

```sh
cd baby-diary-frontend
```

### 2. Install dependencies

```sh
npm install
```

### 3. Configure environment variables

Create a .env file in the project root based on .env.example:

```sh
API_URL=http://localhost:5000
```

### 4. Run the application

```sh
npm run dev
```

### 5. Then open:

```
http://localhost:5173
```

### Setup Backend

### 1.Go to baby-diary-backend folder

```sh
cd ..
cd baby-diary-backend
```

### 2. Install dependencies

```sh
npm install
```

### 3. Configure environment variables

Create a .env file in the project root based on .env.example:

```sh
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

### 4. Run the application

```sh
npm run dev
```

### 5. Then open:

```
http://localhost:5000
```
